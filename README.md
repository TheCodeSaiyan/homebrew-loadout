# homebrew-loadout

Homebrew formulae for [Loadout](https://github.com/ntatschner/loadout-cli).

```sh
brew tap thecodesaiyan/loadout
brew install loadout
loadout setup
```

`Formula/loadout.rb` is regenerated by the `loadout-cli` release workflow on
every published release. Edits made here are overwritten; change
`.github/workflows/homebrew.yml` in that repository instead.
